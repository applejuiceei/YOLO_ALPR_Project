# Third-party components

This project uses the following externally maintained components in the Windows PC simulation build.
The binary packages are intentionally excluded from Git.

- OpenCV 4.12.0, Apache-2.0 license. Official asset: `opencv-4.12.0-windows.exe`.
  SHA-256: `b753b14d880b9bc8d89d6acd3b665c040baec0211078435432fcae117db707af`.
- Microsoft ONNX Runtime 1.29.0 CPU x64, MIT license. Official asset:
  `onnxruntime-win-x64-1.29.0.zip`.
  SHA-256: `c9b4b7086b529ad814f428c1bad028e20a25d7dc0699836775faace4ab5b78b2`.
- Rockchip RKNN Model Zoo YOLO11 optimized ONNX model and output definition.
  Source: <https://github.com/airockchip/rknn_model_zoo/tree/main/examples/yolo11>.
- Ultralytics YOLO11 COCO pretrained model lineage. Source referenced by Rockchip:
  <https://github.com/airockchip/ultralytics_yolo11>.
